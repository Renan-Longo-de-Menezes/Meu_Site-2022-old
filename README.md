# Meu_Site-2022-old
## 🌐 Meu Site old — 2022

> Meu primeiro site pessoal, desenvolvido em **2020** durante o **1º ano do curso Técnico em Informática**.

Este projeto foi criado como um espaço para publicar e organizar atividades, exercícios e trabalhos desenvolvidos ao longo do curso. Ele representa uma etapa importante do meu início na programação web e no aprendizado prático de tecnologias fundamentais do desenvolvimento.

🔗 **Acesse o site:** [Meu Site — 2022](https://renan-longo-de-menezes.github.io/Meu_Site-2022-old/)  
📁 **Repositório:** [GitHub](https://github.com/Renan-Longo-de-Menezes/Meu_Site-2022-old)

---

## 📖 Sobre o projeto

O **Meu Site — 2022** foi desenvolvido com o objetivo de reunir conteúdos e projetos acadêmicos realizados durante o curso técnico. Na época, o site serviu como um portfólio inicial, permitindo apresentar atividades práticas e acompanhar minha evolução nos estudos de desenvolvimento web.

Apesar de ser um projeto antigo, ele faz parte da minha trajetória como desenvolvedor e registra meus primeiros contatos com a criação de páginas, estilos, interações e aplicações web.

---

## 🧰 Tecnologias utilizadas

Durante o desenvolvimento, foram aplicados conhecimentos em:

- **HTML** — estruturação das páginas;
- **CSS** — estilização e organização visual;
- **JavaScript** — interatividade e lógica no navegador;
- **PHP** — estudos e atividades envolvendo programação no lado do servidor.

> **Observação:** Como o projeto está hospedado no GitHub Pages, os arquivos PHP não são executados na versão online, pois essa hospedagem atende apenas conteúdo estático.

---

## 🎯 Objetivo

O projeto teve como principais objetivos:

- Centralizar trabalhos e atividades do curso técnico;
- Praticar a estruturação de sites com HTML;
- Desenvolver habilidades de estilização com CSS;
- Aplicar lógica de programação com JavaScript;
- Estudar conceitos iniciais de PHP;
- Construir uma base para futuros projetos web e portfólios.
